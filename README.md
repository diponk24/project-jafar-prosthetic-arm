# Project Jafar – EMG & Voice Controlled Prosthetic Arm

## Overview

Project Jafar is a prosthetic arm prototype designed to explore assistive robotics through EMG-based muscle signal control and voice-command operation.

The arm incorporates a differential mechanism for finger movement, a foldable elbow joint, and rotational elbow motion to replicate essential arm functionalities.

---

## Features

- EMG sensor-based control
- Voice-command operation
- Differential finger actuation mechanism
- Finger folding functionality
- Foldable elbow joint
- Rotatable elbow movement
- Modular design for future upgrades

---

## Working

The prosthetic arm can be controlled using:

1. **EMG Sensors**
   - Detect muscle activity from the user.
   - Convert signals into movement commands.

2. **Voice Commands**
   - Execute predefined actions through voice input.

The system performs:
- Finger folding
- Gripping actions
- Elbow folding
- Elbow rotation
