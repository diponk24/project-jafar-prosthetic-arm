Project Jafar is a prosthetic arm prototype designed to explore assistive robotics through EMG-based muscle signal control aor voice-command operation. The system incorporates a differential mechanism for finger movement, a foldable elbow joint, and rotational elbow motion to mimic essential arm functionalities.
Key Features
EMG sensor-based control
Voice-command operation
Differential finger actuation mechanism
Finger folding functionality
Foldable elbow joint
Rotatable elbow movement
Modular design for future upgrades
Technologies Used
Arduino/ESP32
EMG Sensors
Servo Motors
Voice Recognition Module
Mechanical Differential Mechanism
